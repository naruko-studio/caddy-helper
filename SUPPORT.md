# Support

> **Repository**: [naruko-studio/caddy-helper](https://github.com/narugu-studio/caddy-helper) — A helper tool for [Caddy](https://caddyserver.com/) to create reverse proxy rules, inspired by [nginx-proxy-manager](https://nginxproxymanager.com/). Built with Elysia Fullstack (ElysiaJS + Bun).

Thank you for using **caddy-helper**! Here's how to get help.

## 🐛 Bug Reports

If you've found a bug, please [open an issue](https://github.com/naruko-studio/caddy-helper/issues/new) and include:

- Your environment (OS, Bun version, Caddy version, ElysiaJS version)
- Steps to reproduce
- Expected vs actual behavior
- Any relevant logs, Caddy config output, or error messages

---

## 💡 Feature Requests

  Have an idea to improve reverse proxy management? [Open a feature request](https://github.com/naruko-studio/caddy-helper/issues/new) and describe:

  - The proxy/routing problem you're trying to solve
  - Your proposed solution
  - Any nginx-proxy-manager or Caddy features that inspired it

## 💬 Community & Discussions

For general questions or discussions:

- Use [GitHub Discussions](https://github.com/narugu-studio/caddy-helper/discussions) (if enabled)
- Open an issue with the `question` label

## ⚠️ What We Don't Support

  - Forked or heavily modified versions of this project
  - Caddy versions below 2.x
  - Deployment environments not covered by our documentation
  - Third-party integrations or plugins outside of our scope
